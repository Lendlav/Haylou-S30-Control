# Локальные артефакты / Local-only artifacts

Локальные APK, Ubuntu-пакеты, модели распознавания речи, сторонние Android-библиотеки и результаты сборки не являются частью исходников и не должны попадать в Git. Они исключены из репозитория правилами `.gitignore`; отсутствующие зависимости можно получить заново по инструкциям платформенных README.

Локальный Android debug signing key сохранён вне проекта по умолчанию в `$XDG_DATA_HOME/haylou-s30-control/haylou-debug.keystore` (или `$HOME/.local/share/haylou-s30-control/haylou-debug.keystore`). Сборочный скрипт использует этот ключ, а путь можно задать через `HAYLOU_DEBUG_KEYSTORE`. Это персональный debug-ключ, не предназначенный для публикации приложений.

FCC test report был предоставлен как локальный справочный материал и исключён из Git. Для публикации достаточно ссылки на источник и описания ограничений документа.
