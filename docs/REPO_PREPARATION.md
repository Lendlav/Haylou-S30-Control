# Подготовка репозитория к публикации

## Правила публикации

- В Git включаются исходники приложений и текстовые исследовательские материалы.
- Сборки, APK, модели, SDK-библиотеки, ключи подписи, локальные отчёты и Bluetooth/firmware captures остаются вне Git.
- Перед push проверяйте `git status --short`, список файлов в индексе и исключения через `git check-ignore -v <путь>`.
- Если секрет случайно попал в commit, удаление файла новым commit не удаляет его из истории: публикацию нужно остановить и очистить историю до push.
- Внешние SDK и документы распространяются только в пределах их лицензий и условий источника.

## Сборка публикации

Корневой README связывает инструкции Ubuntu и Android с исследовательскими документами. Локальные debug-ключи используются только для персональной сборки и не входят в репозиторий.
