# Журнал исследования

Хронология по истории работы над проектом. Точные даты старых экспериментов здесь не восстанавливались; порядок событий сохранён без вымышленных временных отметок.

1. Подключены HAYLOU S30 и изучен локальный официальный APK. Подтверждён vendor SPP UUID `FD3D`; соединение через стандартный endpoint `1101` не обеспечивало управление.
2. Создана C++/Qt утилита Ubuntu с регулировкой ANC, EQ-пресетов и системного sink volume. Исправлялись отображение, масштабирование и контраст выпадающих списков.
3. Создано Android-приложение на Java с подключением SPP и медиасессией для действий с экрана блокировки. В телефон его передавали через ADB по запросу пользователя.
4. Выяснено, что тестовый EQ вызов `0x08 / 02 02` не меняет пресет; основной экран производителя отправляет `0xF2`, config ID `7`. Добавлена штатная команда в Ubuntu-приложение; пользователь сообщил, что она работает.
5. После пользовательского сообщения об аналогичной проблеме Android-клиент обновлён на тот же EQ путь. По истории сессии ANC работал; в финальной папке сохранены исходники, не APK.
6. Пользователь поставил вопрос о firmware update и удалении звуков разряда батареи. Выбрана статическая, безопасная линия: не запускать OTA, пока нет способа получить пакет без автоматической установки.
7. Найден публичный репозиторий Jieli `LiteEMF/JL701n_earphone`. Сверен локальный commit, изучен пример low-battery tone и конфигурация UI tone; совпадение с заводской прошивкой S30 не подтверждено.
8. Изучены материалы 52audio о JL7018F и похожих устройствах, пользовательский FCC test report и текстовые сведения о внутренних фото. Локальная FCC копия неполная; фото плат не подтверждены непосредственным просмотром.
9. В настоящем каталоге систематизированы исходники Linux/Android, сведения о протоколе, аппаратные ограничения и безопасный план последующего firmware-анализа.
